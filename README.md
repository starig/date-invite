# Приглашение для Кариночки

Страница на HTML, CSS и JavaScript без зависимостей и сборки.

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 4173
```

Текст находится в `index.html`, оформление — в `styles.css`, поведение кнопок и сердечки — в `script.js`.

## GitHub Pages

Публикация настроена из корня ветки `main` через Settings → Pages → Deploy from a branch. Обновления в `main` публикуются автоматически.

Адрес: https://starig.github.io/date-invite/

Ответ отображается только в браузере посетителя и не отправляется автору. Перезагрузка возвращает страницу к приглашению.
